# clawd-buddy

Um amiguinho Clawd animado na faixa acima do prompt do Claude Code. Ele reage ao que acontece no chat: pensa, escreve, digita no notebook ao rodar comandos e comemora quando termina. Use `/clawd` para abrir o Clawd grande num painel e `/clawd info` para mostrar ou esconder as barras de uso (sessão, semana e contexto) na faixa.
