# clawd-buddy

Um amiguinho Clawd animado na faixa acima do prompt do Claude Code (app desktop). Ele reage ao que acontece no chat: pensa, escreve a resposta, digita no notebook quando roda comandos, comemora quando termina e fica triste se algo dá errado. As frases variam a cada vez.

## Instalar

Dentro do Claude Code, rode os dois comandos e reinicie:

```
/plugin marketplace add mateus250402/clawd-buddy
```

```
/plugin install clawd-buddy@my-mods
```

## Usar

- A faixa do Clawd aparece sozinha acima da caixa de digitar.
- `/clawd` abre o Clawd grande num painel ao lado da conversa.
- `/clawd info` liga ou desliga as barras de uso na faixa: sessão (5h), semana (7d) e contexto, com o tempo até o reinício. Por padrão ficam desligadas.

Se usar o mod `skins`, rode `/skin band off` para não ficar com duas faixas de uso.
